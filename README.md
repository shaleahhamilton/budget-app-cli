## About
Simple **Budget App (CLI)** to plan weekly/biweekly income, expenses, and a savings goal.

### Features
- Set pay frequency (weekly/biweekly) + net amount
- Add/delete expenses per pay period
- Set savings goal per period
- Summary: income, expenses, leftover, % toward goal
- Data persists in `budget_data.json`

### Run
```bash
python3 budget_app.py
